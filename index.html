BlackBoxLab · Experiment 0

Sampling policy
can become anatomy.

Eight initially identical learners inhabit one continuous world. Nobody tells one to become “fast,” another “slow,” another “burst.” Each can look at only one temporal ecology at a time. What it samples trains its local predictor; what its predictor becomes changes where it wants to look next.
The falsification is built in.
If private self-interest makes every learner stare at the same easy signal, there is no spontaneous brain. Try ECOLOGY: it adds only a small crowding cost to finite observation territory, not named roles.

The loop

same starting machinery ↓ different sampling history ↓ different temporal statistics ↓ different local weights ↓ different competence / value ↓ different future sampling ↺

Sampling is not preprocessing here. It is inside the developmental loop.

The symmetry problem

PRIVATE: “I predict this patch well” ↓ look there more ↓ get even better there possible result: everyone discovers the same comfort zone

That failure is useful. A population needs some source of asymmetry, scarce territory, topology, task pressure, developmental gradients, or stochastic history if distinct organs are to stabilize.

What “different computation” means here

Every organ begins with the exact same autoregressive machinery. Only its learned coefficients differ. The little bars are the current weights on lags 1, 2, 4 and 8. Different sampled dynamics should sculpt different temporal filters.

This is intentionally much weaker than claiming cortical organogenesis. It asks whether input ecology can be part of what makes a computational unit become what it is.

Connection to Child

belief → sampling → evidence → belief becomes body → sampling → experience → body

Child showed that observation policy can make a learner epistemically self-sealing. BlackBoxLab asks whether the same feedback, distributed across a population, can create functional differentiation—or a monoculture.

Reproducible receipt

Run python experiments/sampling_policy_organogenesis.py. It compares matched seeds for YOKED, PRIVATE, and ECOLOGY and records coverage, specialization, pairwise lag-weight divergence, and predictive error.

The ecological crowding term is explicit and should be attacked. Random fixed assignment and ordinary mixture-of-experts routing are obvious next baselines.
