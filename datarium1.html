Datarium 1 is not an evolution demo. A domain must first survive a high/low threshold hysteresis test and minimum area/mass floor. Identity then follows pixel overlap on the periodic field. Splits and merges terminate the old IDs and create explicit descendants.

1 · Same physics, corrected observer

φ⁴ wave field + local resource r + periodic boundaries ↓ high / low hysteresis ↓ torus-connected components ↓ area + mass floor

The browser uses the same local-budget mechanism as Three Fates: activity burns resource, resource recovers, and resource gates the local growth term.

2 · Identity is overlap, not a jumping dot

one old ↔ one new continuation one old → many new split many old → one new merge nothing → new birth

Crossing the left/right or top/bottom seam is ordinary motion because the detector lives on the same torus as the field.

3 · What this unlocks

persistent identity ↓ physical phenotype ↓ sister resemblance? ↓ body-carried material? ↓ only then: heredity / divergence
