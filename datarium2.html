What selection means here

Field owns demography. A controller can only alter local field dynamics. If that changes whether its body persists, splits, merges or disappears, it can alter which controller ancestry survives. On a split, EVOLVE mutates the parent matrix. On a merge, parent matrices are blended. This is a hybrid artificial-life model.

The loop

field creates body ↓ lineage carries matrix ↓ scout samples local world ↓ matrix chooses: move / excite / damp / signal ↓ field changes ↓ field decides next demographic event

The attackers

NONE no controller influence HOMEOSTAT hand-coded stabilizer RANDOM matrices exist but heredity is destroyed EVOLVE split → mutation merge → blend

If EVOLVE cannot beat RANDOM/NONE on ecological outcomes, inherited matrices have not earned anything.
